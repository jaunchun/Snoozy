# Snoozy
**Snoozy** is a small ESP32 handheld console made from random parts I had lying around.

The main idea is simple: **minimal hardware, minimal graphics, maximum battery life.**

### Hardware

* ESP32
* Small OLED display
* Flat analog joystick
* 5 buttons
* Buzzer
* Battery

### Features

Snoozy focuses on:

* 🔋 Good battery life
* 💤 Low-power sleep modes
* Minimalistic graphics and animations
* Simple games
* Small and lightweight hardware
* Smooth little idle/sleep animations

The console is designed to feel alive even when you're not using it. When left alone, it can slowly transition from idle animations into its favorite activity:

**sleeping.**

### Status

Snoozy is currently a work in progress. Hardware, software, games and animations are still being developed.

> **Snoozy doesn't need to be powerful. It just needs to be Snoozy.**
